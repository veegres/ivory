# Playground — coming soon

A live Ivory you can click through in the browser, with a real high-availability cluster behind it, is on
its way.

Until then, Ivory runs on your own machine in one command:

```bash
docker run -p 80:80 --restart always veegres/ivory
```

Open http://localhost:80 and follow [Getting started](/docs/getting-started).

Want to know when the playground opens? **[Watch the repository on GitHub](https://github.com/veegres/ivory)**
for releases.
